# Web-I

Prácticas y misiones de la asignatura **Web Development I** (U-tad, 3.º).

## Índice

| Carpeta | Qué es | Tipo |
| --- | --- | --- |
| [Mision 1](Mision%201/) | **Caza la Mano**: whack-a-mole de 3 × 3 con póker en HTML, CSS y JavaScript puro. Atrapas cartas de una baraja real para formar manos, con tabla de premios, rachas, récord y modo noche secreto. [Ver README](Mision%201/README.md) | Misión M1 · El Despertar del DOM (entrega) |
| [Mision 2](Mision%202/) | **La Despensa**: buscador de recetas con la API TheMealDB, hecho con Vite y módulos ES (`fetch` + `async/await`, estados de carga y error, filtros por categoría y caché en `localStorage`). [Ver README](Mision%202/README.md) | Misión M2 · Async Odyssey (entrega) |
| [Mision 3](Mision%203/) | **La Despensa en React**: la M2 reconstruida con React 19 y Vite (componentes, estado derivado, efectos con limpieza) y una lista de la compra persistente con el hook `useLocalStorage`. [Ver README](Mision%203/README.md) | Misión M3 · Reactor Core (entrega) |
| [Tema1/Oraculo](Tema1/Oraculo/) | El oráculo de los números: adivinar un número del 1 al 100 en 7 intentos. | Ejercicio de clase del Tema 1 |

## Cómo abrir los proyectos

La Misión 1 y el Oráculo son HTML, CSS y JavaScript sin dependencias: basta
con abrir el `index.html` en el navegador (o con Live Server).

Las Misiones 2 y 3 usan Vite: `cd "Mision 2"` (o `"Mision 3"`), `npm install` y `npm run dev`.
